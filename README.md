# Game Ngoc Rong C++

Game console đơn giản theo phong cách Dragon Ball bằng C++.

## Tính năng
- Di chuyển trên bản đồ 12x10
- Thu thập 7 viên Ngọc Rồng
- Chạm trán quái vật
- Tấn công đối thủ gần nhất
- Win/lose logic rõ ràng

## Cách chạy trên Windows
1. Mở Visual Studio / Code::Blocks / Dev C++
2. Tạo project mới C++ Console
3. Thêm file `main.cpp`
4. Build và chạy

## Lệnh người chơi
- W / A / S / D: di chuyển
- C: thu thập viên Ngọc Rồng
- F: tấn công
- Q: thoát
